# POC — Documentação de APIs

Esta é uma prova de conceito (POC) para validar o uso do
[Docusaurus](https://docusaurus.io/) na publicação da documentação das nossas
APIs.

## O que estamos validando

- Organização do conteúdo em páginas e categorias.
- Navegação, busca e tema claro/escuro.
- Publicação automática no GitHub Pages a cada push na branch `main`.
- Facilidade para o time escrever e revisar documentação em Markdown.

## O que tem nesta versão

Esta versão foi reduzida ao mínimo para testar o deploy:

- Esta página de visão geral.
- Uma [API de exemplo](/docs/apis/exemplo) com endpoint, parâmetros e respostas.

O blog, os tutoriais e as páginas de exemplo do template original foram
removidos.

## Status

**Em validação com o time.** Depois do retorno, vamos incluir as APIs reais e
os guias de uso.

## Como contribuir

1. Edite ou crie arquivos `.md` / `.mdx` dentro de `docs/`.
2. Rode `npm run start` para visualizar as mudanças localmente.
3. Abra um pull request para a branch `main`.

O deploy é feito automaticamente pelo GitHub Actions após o merge.
