# Inserir / Criar Cadastro

Cria o cadastro do estudante e o vincula ao contrato de estágio do Itaú,
incluindo os campos específicos do escopo estendido da conta.

## Endpoint

```http
POST /api/v1/integracao/inserir-cadastro
```

## Cabeçalhos

| Cabeçalho | Valor | Obrigatório |
| --- | --- | --- |
| `Authorization` | `Bearer <TOKEN>` | Sim |
| `Content-Type` | `application/json` | Sim |

Obtenha o token em [`POST /auth/login/integracao`](/docs/geral/autenticacao)
utilizando o `clientId` `ITAU_PRD`.

:::info Escopo Itaú e regras de negócio

- O telefone deve obrigatoriamente seguir o formato `(XX) XXXXXXXXX`.
- Se o CPF já existir, a API realiza um **upsert**: atualiza o cadastro
  existente em vez de criar um duplicado.
- `codigoCentroCusto` e `matriculaGestor` são obrigatórios para o contrato Itaú.
- `contratoId`, `supervisorId`, `cursoId` e `localEstagioId` precisam pertencer
  ao mesmo contrato informado.
- O retorno `201` indica criação; o retorno `200` indica atualização de um
  cadastro já existente.

:::

```http

```

```json
  "status": "SUCESSO",
  "mensagem": "Cadastro processado com sucesso.",
  "cpf": "987.654.321-00",
  "contratoId": "ctr_itau_2026_014",

  "dataProcessamento": "2026-10-31T18:15:27Z"

```

## Códigos de status

| Código | Descrição |
| --- | --- |
| `201` | Cadastro criado com sucesso. |
| `200` | Cadastro existente atualizado via upsert. |
| `400` | Dado inválido, campo obrigatório ausente ou telefone fora do padrão `(XX) XXXXXXXXX`. |
| `401` | Token ausente, inválido ou expirado. |
| `500` | Erro interno ao processar o cadastro. |
