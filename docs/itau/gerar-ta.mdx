# Gerar TA (Termo Aditivo)

Gera um Termo Aditivo (TA) para alterar condições de um contrato de estágio do
Itaú.

## Endpoint

```http
POST /api/v1/integracao/gerar-ta
```

## Cabeçalhos

| Cabeçalho | Valor | Obrigatório |
| --- | --- | --- |
| `Authorization` | `Bearer <TOKEN>` | Sim |
| `Content-Type` | `application/json` | Sim |

Obtenha o token em [`POST /auth/login/integracao`](/docs/geral/autenticacao)
utilizando o `clientId` `ITAU_PRD`.

:::info Escopo Itaú e regras de negócio

- O contrato original precisa estar `ATIVO` e possuir TCE gerado.
- `idDocumentoOriginal` deve referenciar o TCE retornado por
  [`gerar-tce`](/docs/itau/gerar-tce).
- O TA pode alterar data de término, valor da bolsa, jornada semanal e local de
  estágio.
- Para prorrogações com troca de supervisor, utilize também a rota
  [`prorrogacao-alterar-supervisor`](/docs/itau/prorrogacao-alterar-supervisor).
- O TA assinado deve ser enviado pela rota
  [`receber-contrato-assinado`](/docs/itau/receber-contrato-assinado).

:::

## Exemplo de requisição

```bash
curl -X POST "https://api.ciee.org.br/api/v1/integracao/gerar-ta" \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "idContrato": "ctr_itau_2026_014",
    "idDocumentoOriginal": "doc_tce_7a12f4c8",
    "tipoAditivo": "PRORROGACAO",
    "dataVigencia": "2027-11-10",
    "novaDataFim": "2028-11-09",
    "novoValorBolsa": 2400.00,
    "novaJornadaSemanal": 30,
    "novoLocalEstagioId": "loc_315",
    "motivo": "Prorrogação do contrato conforme avaliação de desempenho."
  }'
```

```json
{
  "idContrato": "ctr_itau_2026_014",
  "idDocumentoOriginal": "doc_tce_7a12f4c8",
  "tipoAditivo": "PRORROGACAO",
  "dataVigencia": "2027-11-10",
  "novaDataFim": "2028-11-09",
  "novoValorBolsa": 2400.00,
  "novaJornadaSemanal": 30,
  "novoLocalEstagioId": "loc_315",
  "motivo": "Prorrogação do contrato conforme avaliação de desempenho."
}
```

## Exemplo de resposta

```http
HTTP/1.1 201 Created
```

```json
{
  "idDocumento": "doc_ta_1e84b6f3",
  "status": "SUCESSO",
  "tipoDocumento": "TA",
  "idContrato": "ctr_itau_2026_014",
  "idDocumentoOriginal": "doc_tce_7a12f4c8",
  "urlDocumento": "https://docs.ciee.org.br/ta/doc_ta_1e84b6f3.pdf",
  "mensagem": "Termo aditivo gerado com sucesso.",
  "dataGeracao": "2026-10-31T19:08:42Z"
}
```

## Códigos de status

| Código | Descrição |
| --- | --- |
| `201` | Termo aditivo gerado com sucesso. |
| `200` | Termo aditivo já existente e retornado sem nova geração. |
| `400` | Dado inválido, contrato inelegível ou telefone fora do padrão `(XX) XXXXXXXXX`. |
| `401` | Token ausente, inválido ou expirado. |
| `500` | Erro interno ao gerar o termo aditivo. |
