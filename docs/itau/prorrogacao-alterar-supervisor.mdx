# Prorrogação: Alterar Supervisor

Altera o supervisor responsável durante o fluxo de prorrogação de um contrato de
estágio do Itaú.

## Endpoint

```http
PUT /api/v1/integracao/prorrogacao/alterar-supervisor
```

## Cabeçalhos

| Cabeçalho | Valor | Obrigatório |
| --- | --- | --- |
| `Authorization` | `Bearer <TOKEN>` | Sim |
| `Content-Type` | `application/json` | Sim |

Obtenha o token em [`POST /auth/login/integracao`](/docs/geral/autenticacao)
utilizando o `clientId` `ITAU_PRD`.

:::info[Escopo Itaú e regras de negócio]

- Rota exclusiva do escopo estendido do Itaú.
- O contrato precisa estar `ATIVO` e possuir uma prorrogação em andamento.
- O novo supervisor deve estar `ATIVO`, pertencer ao mesmo contrato e ter
  centro de custo compatível.
- O `novoSupervisorId` não pode ser igual ao `supervisorAtualId`.
- A alteração não gera um novo TCE; o TA da prorrogação deve ser gerado depois
  pela rota [`gerar-ta`](/docs/itau/gerar-ta).

:::

## Exemplo de requisição

```bash
curl -X PUT "https://api.ciee.org.br/api/v1/integracao/prorrogacao/alterar-supervisor" \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "idContrato": "ctr_itau_2026_014",
    "idProrrogacao": "prg_6f2a91c3",
    "supervisorAtualId": "sup_2087",
    "novoSupervisorId": "sup_2099",
    "dataVigencia": "2027-11-10",
    "motivo": "Substituição do supervisor por mudança de área do gestor."
  }'
```

```json
{
  "idContrato": "ctr_itau_2026_014",
  "idProrrogacao": "prg_6f2a91c3",
  "supervisorAtualId": "sup_2087",
  "novoSupervisorId": "sup_2099",
  "dataVigencia": "2027-11-10",
  "motivo": "Substituição do supervisor por mudança de área do gestor."
}
```

## Exemplo de resposta

```http
HTTP/1.1 200 OK
```

```json
{
  "idContrato": "ctr_itau_2026_014",
  "idProrrogacao": "prg_6f2a91c3",
  "status": "SUCESSO",
  "supervisorAnteriorId": "sup_2087",
  "supervisorAtualId": "sup_2099",
  "dataVigencia": "2027-11-10",
  "mensagem": "Supervisor da prorrogação alterado com sucesso.",
  "dataProcessamento": "2026-10-31T20:02:18Z"

```

## Códigos de status

| Código | Descrição |
| --- | --- |
| `200` | Supervisor da prorrogação alterado com sucesso. |
| `201` | Alteração registrada e enviada para validação assíncrona. |
| `400` | Dado inválido, supervisor inelegível ou telefone fora do padrão `(XX) XXXXXXXXX`. |
| `401` | Token ausente, inválido ou expirado. |
| `500` | Erro interno ao alterar o supervisor da prorrogação. |
