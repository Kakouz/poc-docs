# Buscar Locais de Estágio

Lista os locais de estágio autorizados para os contratos do Itaú.

## Endpoint

```http
GET /api/v1/integracao/buscar-locais-contrato?contratoId=ctr_itau_2026_014
```

## Cabeçalhos

| Cabeçalho | Valor | Obrigatório |
| --- | --- | --- |
| `Authorization` | `Bearer <TOKEN>` | Sim |
| `Accept` | `application/json` | Sim |

Obtenha o token em [`POST /auth/login/integracao`](/docs/geral/autenticacao)
utilizando o `clientId` `ITAU_PRD`.

:::info[Escopo Itaú e regras de negócio]

- `contratoId` é obrigatório e limita a consulta aos locais vinculados ao
  contrato Itaú.
- Os filtros `cidade` e `uf` são opcionais.
- Apenas locais ativos, com centro de custo compatível e vagas disponíveis são
  retornados.
- O `localEstagioId` retornado deve ser usado nas rotas `inserir-cadastro`,
  `atualizar-cadastro` e `gerar-tce`.

:::

## Exemplo de requisição

```bash
curl -X GET "https://api.ciee.org.br/api/v1/integracao/buscar-locais-contrato?contratoId=ctr_itau_2026_014&cidade=São%20Paulo&uf=SP" \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Accept: application/json"
```

```json
{
  "contratoId": "ctr_itau_2026_014",
  "cidade": "São Paulo",
  "uf": "SP"
}
```

## Códigos de status

| Código | Descrição |
| --- | --- |
| `200` | Consulta realizada com sucesso, com ou sem resultados. |
| `400` | `contratoId` ausente, UF inválida ou parâmetro fora do formato esperado. |
| `401` | Token ausente, inválido ou expirado. |
| `500` | Erro interno ao consultar os locais de estágio. |
