# Buscar Cursos do Contrato

Lista os cursos habilitados para os contratos de estágio do Itaú.

## Endpoint

```http
GET /api/v1/integracao/buscar-cursos?contratoId=ctr_itau_2026_014
```

## Cabeçalhos

| Cabeçalho | Valor | Obrigatório |
| --- | --- | --- |
| `Authorization` | `Bearer <TOKEN>` | Sim |
| `Accept` | `application/json` | Sim |

Obtenha o token em [`POST /auth/login/integracao`](/docs/geral/autenticacao)
utilizando o `clientId` `ITAU_PRD`.

:::info[Escopo Itaú e regras de negócio]

- `contratoId` é obrigatório e define os cursos disponíveis para o contrato.
- Apenas cursos ativos e vigentes na data da consulta são retornados.
- O `cursoId` retornado deve ser usado nas rotas `inserir-cadastro`,
  `atualizar-cadastro` e `gerar-tce`.
- Cursos de nível técnico e superior seguem as regras do contrato Itaú.

:::

## Exemplo de requisição

```bash
curl -X GET "https://api.ciee.org.br/api/v1/integracao/buscar-cursos?contratoId=ctr_itau_2026_014" \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Accept: application/json"
```

```json
{
  "contratoId": "ctr_itau_2026_014"
}
```

## Códigos de status

| Código | Descrição |
| --- | --- |
| `200` | Consulta realizada com sucesso, com ou sem resultados. |
| `400` | `contratoId` ausente ou em formato inválido. |
| `401` | Token ausente, inválido ou expirado. |
| `500` | Erro interno ao consultar os cursos. |
