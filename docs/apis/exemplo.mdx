# API de exemplo

Esta é uma API fictícia, usada apenas para demonstrar como uma referência de
API pode ser escrita no Docusaurus.

## Endpoint

```http
GET /v1/hello
```

Retorna uma mensagem de saudação.

### Parâmetros de consulta

| Nome    | Tipo   | Obrigatório | Descrição                         |
| ------- | ------ | ----------- | --------------------------------- |
| `name`  | string | Não         | Nome que será usado na saudação.  |

### Exemplo de requisição

```bash
curl "https://api.exemplo.com/v1/hello?name=Time"
```

### Exemplo de resposta

```json
{
  "message": "Olá, Time!",
  "timestamp": "2026-10-31T12:00:00Z"
}
```

### Códigos de status

| Código | Descrição                        |
| ------ | -------------------------------- |
| `200`  | Requisição processada com sucesso. |
| `400`  | Parâmetro inválido.              |
| `500`  | Erro interno do servidor.        |

:::info

Este endpoint não existe de verdade. O conteúdo serve somente para validar o
formato da documentação.

:::
